# Programa feito na linguagem VisualG que valida múltiplos CPFs digitados número por número através de uma estrutura de repetição. Ele calcula e compara os dígitos verificadores para determinar a veracidade do documento. Ao final, o programa exibe um relatório contendo o total de testes realizados e as porcentagens de CPFs válidos e inválidos.
